SOLUCIÓN DE PROBLEMAS
================================================================================

PROBLEMA: Los logos no se muestran
SOLUCIÓN:
  1. python check_logos.py
  2. python backend/scripts/cargar_logos_reales.py
  3. Ctrl + Shift + R en el navegador

PROBLEMA: Los avatares no tienen color
SOLUCIÓN:
  1. Verificar que el partido tenga color en BD
  2. Actualizar desde dashboard de super admin
  3. Verificar formato hexadecimal (#RRGGBB)

PROBLEMA: Error de CORS
SOLUCIÓN:
  Los logos de placeholder.com no tienen problemas de CORS
  Si usas otra fuente, verifica que permita CORS

================================================================================
AGREGAR LOGO A UN PARTIDO
================================================================================

OPCIÓN 1: Desde Dashboard
  1. Ir a "Configuración > Partidos Políticos"
  2. Click en "Editar" (ícono de lápiz)
  3. Ingresar URL del logo
  4. Guardar cambios

OPCIÓN 2: Desde Script
  1. Editar backend/scripts/cargar_logos_reales.py
  2. Agregar en LOGOS_PARTIDOS:
     'CODIGO_PARTIDO': 'https://url-del-logo.com/imagen.png'
  3. Ejecutar: python backend/scripts/cargar_logos_reales.py

OPCIÓN 3: Desde Base de Datos
  UPDATE partidos 
  SET logo_url = 'https://url-del-logo.com/imagen.png'
  WHERE codigo = 'CODIGO_PARTIDO';
