📊 MÉTRICAS CALCULADAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Score de Rendimiento:
  ┌────────────────────────────────────────────────────────────┐
  │ Score = (Presencia% × 0.4) +                               │
  │         (Validados% × 0.4) +                               │
  │         (Penalización_Incidentes × 0.2)                    │
  └────────────────────────────────────────────────────────────┘

  Índice de Actividad:
  ┌────────────────────────────────────────────────────────────┐
  │ Índice = Usuarios + Formularios +                          │
  │          (Incidentes × 2) + (Delitos × 3)                  │
  └────────────────────────────────────────────────────────────┘

  Tasa de Cambio:
  ┌────────────────────────────────────────────────────────────┐
  │ Tasa = ((Actual - Anterior) / Anterior) × 100              │
  └────────────────────────────────────────────────────────────┘
